# 默认段曲线类型：只在曲线诞生时读一次，不回溯

## Status

accepted

## 背景

段曲线类型（线性 / 平滑 / 快速 / 慢速，见 `CONTEXT.md`）此前是**造段时硬编码的
线性**：新建曲线一律是"一整段线性"，用户想让线出来就是平滑的，只能建完再右键
选一次。Vegas 的开箱行为是**平滑**——同一根线拖出来就是 S 形成型，线性是可选的
一档。用户要求把这个"新曲线的默认形状"做成面板里可下拉的设置。

难点不在选项，而在**作用域**。这条设置一旦被理解成"新段一律取默认"，就会跟两条
既有承诺打架：

1. **拆段继承**（"点插上去，线不动"，见 `CONTEXT.md`「段曲线类型」）——插点把一段
   劈成两段。若新段取默认，默认=平滑时双击插点会让整条线当场变形（两个 S 半段在
   接点处还多一折），用户会把插点当成"改坏了的操作"；
2. **旧文件形状不变**——`seqvel_curve_types` 属性是 v1.2.7 才有的，此前存盘的曲线
   没有类型载荷。若"缺类型 = 取默认"，默认=平滑会让打开旧工程时所有老曲线当场
   变形成 S。

## 决定

1. **默认只在曲线诞生那一刻读一次**——即建默认曲线时（= 首次按住一条还没有速度
   曲线的条带）。此后这条曲线的段类型与设置无关。损坏载荷的修复路径也算"诞生"
   （那确实是一条新曲线，且两端都是 1.0x，形状上无从观察）。
2. **默认值 = 平滑**（复刻 Vegas 开箱行为）。四档全开放（线性 / 平滑 / 快速 /
   慢速）：面板下拉与右键段菜单共用同一套档名与档数，**不新造**"能当默认的两档"
   这种第二套近义词表。
3. **既有规则一条不改**：拆段（插点）继承原段类型、并段（删点 / 吞点）取左段
   类型——默认不介入这两处。
4. **无从继承时仍退回线性，不看默认**：旧文件缺 `seqvel_curve_types`、或类型序列
   短于段数需要补齐时，一律读/补成线性。默认不是"兜底值"，而是"诞生值"——没有
   这一条，把默认设成平滑就等于悄悄重写了所有旧工程的形状。
5. **设置住在场景上**（`scene.seqvel`，与 `hide_native_retiming` / `show_hud` 同一
   处），面板里一个下拉。**不迁移存量值**：旧 .blend 里没这条属性 → 取属性默认
   （平滑）；已有曲线里写着什么就是什么。旧文件里原本勾着的「显示速度百分比」
   保持勾着，要改成不勾由用户自己点一次——静默改用户存盘的设置是越权。
6. **连带修正：恒速的非线性段只需两端关键帧**。承载写入原先的规则是"非线性段
   逐帧写"，但 `v0 == v1` 时任何缓动都退化成常数，两端点与逐帧写在数学上等价。
   默认=平滑让"平坦的平滑段"从边角变成常态（新曲线的初始态就是它）——不改这条，
   在平坦的新线上插一个点就会给 120 帧的素材写出 ~120 个全是 1.0x 的关键帧，
   面板的「关键帧 n 个」也会跟着吓人。判据是纯数学的（两端速度相等即可），与
   档位无关（快速 / 慢速同理），语义零变化。

## 考虑过的选项

- **默认介入拆段**（"新段一律取默认"）：否——破"点插上去、线不动"，且默认=平滑时
  插点立刻改变线的形状。
- **下拉只给两档**（用户最初只提"线性或者平滑"）：否——段的档位是四档，再来一套
  "能当默认的两档"就是第二套近义词表，以后加档要改两处。
- **设置搬去插件偏好（AddonPreferences）**：否（本次）——与既有设置同构、面板一个
  下拉最省；代价是每个 .blend 各存一份，真嫌烦再搬，改动量很小。
- **迁移存量**（把旧文件里的 `show_hud=True` 一次性改 False、把缺类型的曲线按默认
  重铺）：否——静默改用户存盘数据，且无法区分"旧默认留下的"与"用户特意设的"。
- **什么都不做，让用户右键选**：否——那正是现状；用户要的是"新线开箱即平滑"。

## 后人不该"简化"回去的理由

失败模式很具体：后来者看到建默认曲线时不直接写 `LINEAR`、而是绕一层"从条带所属
场景读设置"，会当成无谓耦合，顺手改回硬编码线性——于是新曲线又变回直线倾斜，而
这个回归**不报错、不崩、只是形状不对**，只有在真机上"拖点出来不是 S 形"才察觉得到。

同理，看到"两端速度相等就只写两个关键帧"，有人会当成过早优化删掉，让每段缓动都
逐帧写——数据量与面板上的关键帧数一起膨胀。

回归用例须**带语义**地钉住：新曲线取默认（出厂平滑）、改默认不回溯既有曲线、缺
类型载荷仍读全线性、插点继承不因默认而变、恒速缓动段的关键帧只有两端点。
